# Mahjong tile faces

The 34 tile faces are from [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) (the `Regular` set), which its README places in the public domain (CC0). They are unchanged.

`../parlour.jpg`, the table behind them, and `../parlour-upright.jpg`, the same parlour drawn taller than wide for upright phones, were generated for this project with an image model. The four pictures in `../wall` are stacks of two tiles rendered for this project in Blender.
